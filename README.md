# Berry - A feature-rich task management app

Built using **Next.js App Router**, **TypeScript**, **Tailwind**, **Shadcn**, **Postgres**, **Clerk**, & **Cloudflare Workers AI**.

![Berry](/public/berry-app-screenshot.png)

## Features

- 💻 Beautiful landing page
- 🔑 Authentication using Clerk
- 🗂️ Drag-and-drop cards and lists
- 🌟 Clean, modern UI on top of shadcn-ui
- 📩 Real-time board features
- 🤖 AI integration for text generation.
- 🚀 100% written in TypeScript

## Prerequisites

- Node.js: >= 18.x
- PostgreSQL: Installed locally or accessible remotely
- An account with Supabase and Clerk to obtain API keys.

## Installation

1\. Clone the repository

```
git clone https://github.com/leartt/berry.git
```

2\. Setup environment variables

- Copy .env.example to a new file named .env and update the .env with your actual values.

3\. Install dependencies

```
npm install
```

4\. Run the Development Server

```
npm run dev
```

The app should now be running at http://localhost:3000.
